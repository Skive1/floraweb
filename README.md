\# 🌸 Flora Shop



Flora Shop is a Java Servlet-based e-commerce web application developed for academic purposes in the SWP391 course.  

The project simulates a modern online flower shopping platform where customers can browse products, manage carts, place orders, and interact with the system through a user-friendly interface.



> ⚠️ This project was developed for educational and learning purposes only.



\---



\## 🚀 Features



\### 👤 Customer Features

\- User registration \& authentication

\- Browse flower products by categories

\- Product search \& filtering

\- Shopping cart management

\- Checkout \& order placement

\- User profile management

\- Order history tracking



\### 🛠️ Admin Features

\- Product management (CRUD)

\- Category management

\- Order management

\- User management

\- Dashboard statistics
